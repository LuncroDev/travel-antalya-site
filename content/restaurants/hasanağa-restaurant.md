Hasanağa’s restaurant-hosted Eatbu page identifies a Turkish restaurant at Mescit Sokak No:15 in Kaleiçi, serving fish and grills. A more recent Antalya Bar Association listing dated 23 July 2025 names the same address Karma Kaleiçi Restoran and refers to it as Hasanağa Karma. These sources establish the location but leave the current operating name and continuity unresolved.

## Identity and location

This location is distinct from Karma Side in Manavgat. The old Eatbu page remains accessible, but it is not sufficient evidence that its published hours or menu still apply to the current business.

## Before visiting

Confirm the current name, menu and service directly before travelling. No fully verified current official website was found for the Karma Kaleiçi branding, so this profile does not claim live availability or publish hours.
